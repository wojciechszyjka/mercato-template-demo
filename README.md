# mercato-template-demo

A demo Open Mercato app template, made with [create-mercato-template](https://github.com/open-mercato/create-mercato-template) for the QA of [open-mercato/open-mercato#8732](https://github.com/open-mercato/open-mercato/pull/8732) (`create-mercato-app --template`).

It is a stock app from `create-mercato-app@0.9.0 --preset classic` with no third-party modules. Create an app from it with:

```bash
npx create-mercato-app my-app --template wojciechszyjka/mercato-template-demo
```
